# ClipBridge · 手机 ↔ 电脑 文本/图片剪贴桥

在手机和电脑之间互传文本与图片：**电脑上复制 → 手机取走**，**手机上传 → 电脑看图**。
不用装 App、不用账号、不用联网 —— 电脑跑一个小服务，手机浏览器打开即可。

- 零第三方依赖，只用 Node 内置模块（Node ≥ 18）
- **一条命令启动**：`node start.js` 自动体检环境、挑端口、打印二维码
- 手机**扫码**直接打开，不用手输 IP
- 文本自动同步；图片可多选上传、全部保留、逐张预览与保存
- 服务的默认行为**不碰你的系统剪贴板**（只有你显式运行 `clip`/`pull` 才会）
- 内容只存在你自己电脑的**内存**里，服务一停就没了

## 快速开始

```powershell
cd clipbridge
node start.js        # 推荐：先体检环境，再自动挑端口启动
```

Windows 上也可以**直接双击 `启动.cmd`（或 `start.cmd`）**：找不到 Node 会提示、Node 太旧会提示、
出错也会停住让你看信息 —— 不会一闪而过。

> 为什么有两个 .cmd：`启动.cmd` 只是中文名的转发入口，真正干活的 `start.cmd` **内容全是 ASCII**。
> 因为 `cmd.exe` 用系统 OEM 代码页解析 .cmd，文件里写中文（UTF-8）会导致语法错乱、窗口闪退；
> 所以所有中文输出都由 `start.js` 打印。

`node start.js` 会依次检查：Node 版本 ≥ 18、必需文件是否齐全、有没有可用的局域网网卡、
状态文件能不能写、剪贴板助手是否可用、端口是否被占用（**被占用会自动往后找可用端口**），
体检通过后才启动服务并打印二维码：


启动器参数：

| 命令 | 作用 |
| --- | --- |
| `node start.js` | 体检 + 启动（端口被占用自动往后找） |
| `node start.js --check` | **只体检**，不启动（排查问题用） |
| `node start.js --test` | 体检 + 跑一遍自测（二维码编码器等） |
| `node start.js --port 9000` | 指定端口 |
| `node start.js --token 口令` | 加访问口令（网址变成 `?k=口令`） |
| `node start.js --reset` | 启动前清空已保存的文本 |
| `node start.js --open` | 启动后自动打开电脑上的页面 |
| `node start.js --no-qr` | 不打印二维码 |
| `node start.js --host 127.0.0.1` | 只允许本机访问（手机就连不上了） |

**手机连上同一个 Wi-Fi，用相机扫二维码**即可打开页面。电脑上直接打开 `http://127.0.0.1:8737/`。

### 页面结构（文本区 / 图片区 / 文件区，三块互不影响）

**上面的文本区**（唯一的主框）：

| 操作 | 作用 |
| --- | --- |
| **复制** | 把文本写入**本机**剪贴板，接着去任意 App 里粘贴 |
| **同步** | 把编辑框内容手动发给另一台设备（Ctrl+Enter 也行） |
| **清空文本** | 立即清空两台设备的文本（不再询问） |
| 自动发送开关 | 默认开，编辑框停止输入约 0.8 秒后自动同步文本 |

**中间的图片区**：

| 操作 | 作用 |
| --- | --- |
| **选择图片** | 手机可多选上传；也可以把图拖进来 / 粘贴（Ctrl+V） |
| 缩略图网格 | 只用来预览图片，一行多个；每张图上有**半透明的文件名 + 大小**（悬停/触摸时更清楚） |
| 缩略图右上 ⤓ | **直接保存这张图片**（不用点开大图） |
| 缩略图右上 × | 删除该张图片 |
| 点缩略图 | 放大查看，弹窗里也有「保存图片」 |
| **清空图片** | 立即清空两台设备的图片（不再询问） |

**下面的文件区**（逻辑与图片区一致，用来传一般文件：文档/压缩包/安装包/任意类型）：

| 操作 | 作用 |
| --- | --- |
| **选择文件** | 手机可多选上传（不限类型）；也可以把文件拖进页面 |
| 文件列表 | 一行一个：类型图标 + 文件名 + 大小/来源/时间 |
| **下载** | 电脑端点了直接存到"下载"目录；手机端点了存到"文件/下载" |
| **删除** | 删掉这一个文件 |
| **清空文件** | 立即清空两台设备的文件（不再询问） |

- **图片与文件全部保留**：连着传多个也**不会覆盖**前面的。图片上限 12 张 / 48 MB；
  **文件不限大小、不限数量**（只受电脑内存约束），注意越大越占内存，传完可以点「清空文件」释放。
- **拖入自动分流**：拖进来的一堆文件里，图片自动进图片区，其它类型自动进文件区。
- **文件名会做安全清洗**（只取末段、去掉控制字符），不会因为文件名里的 `../` 或 `C:\` 写到别的目录。
- **服务的默认行为不碰你的剪贴板**：上传图片只是进图片区，不会自动写进系统剪贴板；
  收到别处的新内容也不会自动覆盖你的剪贴板。想看图片点缩略图，想下载点「保存图片」。
- **没有「读取电脑剪贴板」按钮**：电脑上复制的东西，在编辑框里直接 `Ctrl+V` 粘贴即可
  （手机端长按粘贴）。图片没法通过粘贴传过来，请用「选择图片」或把文件拖进页面。
- **启动时编辑框是空的**：那句提示是**灰色占位文字**（placeholder），不是真实内容 ——
  你一输入或粘贴就自动消失，绝不会挡住你的粘贴内容。

### 文本：怎么"复制进来"和"复制出去"

- **复制出去**：点「复制」→ 去任意 App `Ctrl+V`/长按粘贴。
- **复制进来**：在编辑框里直接粘贴（手机长按粘贴）。粘贴后如果自动发送是开着的，会立刻同步给另一台设备。
- **手动同步**：点「同步」或按 `Ctrl+Enter`。

### 图片：怎么传

**电脑 → 手机**（在资源管理器里 `Ctrl+C` 复制图片文件，然后手机点「读取电脑剪贴板」）：

- 手机端看到**图片缩略图**（点击可放大/下载）
- 同时显示**电脑上的完整路径**，并有「复制文件路径」按钮 —— 把路径粘到微信/QQ/钉钉输入框，
  对方直接收到原图文件（比发压缩后的图片更清晰）
- 一共复制了多张图片就会一次全部同步

**手机 → 电脑**（网页里「选择图片上传」/ 拖进来 / 直接 `Ctrl+V` 粘贴图片）：

- 图片**直接写入电脑系统剪贴板**，不落盘
- 电脑上打开微信/QQ/画图/PS，直接 `Ctrl+V` 就能发送或编辑
- 支持多选；单张上限 12 MB，同时支持 PNG / JPEG / GIF / BMP / WebP

> **关于浏览器剪贴板**：网页只有处在**安全上下文**（HTTPS 或 localhost）时才被允许读写剪贴板。
> 手机通过 `http://192.168.x.x` 访问属于不安全上下文，所以：
> - 「读取电脑剪贴板」由**服务端**代读（因此手机端一定能看到内容）
> - 「复制」走自动选中+复制的兜底路径；若系统拦截，长按内容手动复制即可
> - 图片「复制到本机剪贴板」在支持的浏览器里可用，不支持时可点「打开 / 下载」保存到相册

## 命令行用法（电脑端）

```powershell
node server.js                       # 启动网页服务（默认 8737 端口）
node server.js --open                # 启动并自动打开本机页面
node server.js send "要发到手机的文字"  # 直接推送到共享剪贴板
echo 多行文本 | node server.js send -   # 从标准输入读取后推送
node server.js pull                  # 把文本写入电脑剪贴板（仅在你显式调用时）
node server.js clip                  # 监听电脑剪贴板（文本+图片），变化即同步
```

参数：

| 参数 | 说明 |
| --- | --- |
| `-p, --port <端口>` | 监听端口，默认 `8737`；被占用时换一个即可 |
| `--host <地址>` | 监听地址，默认 `0.0.0.0`（局域网可访问）；只想本机用可设 `127.0.0.1` |
| `--token <令牌>` | 访问口令，URL 变为 `http://ip:端口/?k=令牌`，防止同网段其他设备乱看 |
| `--store <路径>` | 持久化文件位置，默认 `./data/clipboard.json`（只存文本） |
| `--no-qr` | 不打印二维码 |
| `--open` | 启动后自动打开浏览器 |
| `-q, --quiet` | 安静模式 |

加口令的推荐启动方式：

```powershell
node server.js --token mysecret --open
```

## 工作原理

```
 手机浏览器  ──┐                          ┌── 电脑浏览器
               ├── HTTP(S) 同一局域网 ─────┤
 手机剪贴板     │  条目列表 + 版本号        │   电脑系统剪贴板
               └── 事件流(SSE)/轮询 ───────┘
```

- 服务端维护**一块文本 + 一组图片**，两者完全独立；文本始终只有一条（同步就是覆盖它），图片则全部保留。
- 图片二进制按内容哈希存在内存里，状态接口只传元数据；超过 12 张或 48 MB 时才会丢最早的。
- 页面每 2 秒轮询 `GET /api/state?since=版本号`，有变化才拉取；同时订阅 `GET /api/events`（SSE）即时推送。
- **服务本身不读写你的系统剪贴板**：只有你显式运行 `node server.js clip` / `pull` 时才会碰它。
- 电脑系统剪贴板交互由 `lib/clipboard-image.ps1`（PowerShell + WinForms）完成：读文本/图片文件/截图，写文本/图片。
- 二维码由内置的零依赖 QR 编码器生成（字节模式、L 级纠错、版本 1–15 自适应），渲染成 PNG 或终端半方块字符。

## 常见问题

**手机打不开页面？**
1. 确认手机和电脑在**同一个 Wi-Fi**（手机别开流量/VPN）。
2. Windows 防火墙首次会弹窗，选**允许**（专用网络）。若已误点拒绝，可在"Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙"里放行 Node.js。
3. 电脑有多张网卡（虚拟机、Docker）时，二维码用的是优先选出的真实网卡地址；若不对，手动输入终端里列出的其他地址，或点页面右上角「手机打开」。

**想把手机上传的图片放进电脑剪贴板？**
- 服务的默认行为不碰剪贴板（这是你要求的手动模式）。需要时可点缩略图 →「保存图片」下载到电脑，
  或运行 `node server.js clip` 让电脑持续把剪贴板内容同步进页面。

**图片重启后不见了？**
- 这是设计如此：图片只在内存中，不写磁盘，服务重启即清空。

**端口被占用？**
```
node server.js --port 8888
```

```powershell
node scripts/check-final.js http://127.0.0.1:8737  # 最终确认（只读，不改数据）
node scripts/check-layout.js                       # 图片区只预览图片、文本不重复显示
node scripts/check-thumb.js                        # 真实执行 renderThumb，校验缩略图结构
node scripts/check-clear-button.js                 # 「清空文本」按钮随内容实时亮灭
node scripts/check-cmd.js                          # 双击入口 .cmd 可靠（纯 ASCII/CRLF/必 pause）
node scripts/check-startup.js                      # 编辑框不预填、只有灰色占位提示

```
